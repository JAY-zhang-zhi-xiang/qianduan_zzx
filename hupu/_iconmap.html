发布 用 CSS 绘制 （icon-jiahao 未采用） U+E60A 加号 3298402
为什么「发布」不用字体图标：包内 icon-jiahao/icon-jiahao-/icon-zengjia 三个加号字形本身都自带一圈圆形外框， 叠在下导航中间的红色圆钮上会出现「圆中套圆」的双环，视觉上脏。
因此中间发布钮用 CSS 伪元素画两条线（横 18×2px + 竖 2×18px）组成加号，见 hupu-mobile.css 的 .zzx-tabbar__plusmark::before / ::after。
其余四个位置全部由 <i class="iconfont icon-xxx"> 渲染，颜色由 CSS color 控制（未选中 #a3a6ab / 选中 #c60100），大小由 font-size 控制——这正是字体图标相对位图方案的优势。
