下导航图标的两种实现技术对比

学号 24002060419 · 张志翔 · 班级 计算机24006  |  图标全部来源于 iconfont.cn（自建项目 zhangzhixiang2026 / id 5244713）
方案 A SVG 符号雪碧图 + <use> 引用 <svg><use href="#zzx-ico-home"></use></svg>
方案 B iconfont 字体图标 + font-class <i class="iconfont icon-index-copy"></i>
两种方案同时实现，是为了满足实验要求「本步所用技术必须与上一步有区别」。
同一套导航、同一份 CSS 布局（.zzx-tabbar 系列类），只有图标承载方式不同：方案 A 把矢量路径内嵌在页面里用 <use> 复用， 方案 B 用 @font-face 加载 woff2/woff/ttf 字体文件，图标变成一个字符，颜色交给 CSS color、大小交给 font-size。
