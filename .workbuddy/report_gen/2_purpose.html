一、实验目的与实验环境

1.1 实验目的

本实验的目标是掌握前端的图像解决方案，重点掌握字体图标（font-class）与 SVG 两种矢量图像的获取与使用方式，能够用 CSS 控制图标的尺寸、颜色与排列，并独立完成四级项目；完成后的下导航同时服务于期末三级项目的导航设计。

1.2 实验环境

硬件：PC（Windows 11）。软件：Visual Studio Code 编辑代码；Google Chrome 与 Microsoft Edge 用于多浏览器测试；图标资源来自 iconfont.cn（阿里巴巴矢量图标库）。调试时使用 Chrome DevTools 的设备模拟（Device Toolbar）切换 320 / 375 / 414 / 768 / 1440 五档视口宽度。

1.3 选题说明

本人的三级项目选题为「虎扑页面复刻」，已完成 PC 端的四个页面（index.html、bbs.html、post.html、channel.html）。虎扑 PC 端站点没有底部下导航，因此按照实验指导书“每位同学的项目内容默认为自己期末三级项目选题的下导航，如果所选项目没有下导航，可以选择其他导航或其他移动网站的下导航”的规定，本实验选择与三级项目同源的虎扑 App 移动端下导航作为复刻对象。
