三、测试与发布

3.1 多视口测试

使用 Chrome DevTools 的设备模拟，分别在 320×640（手机·小屏）、375×812（手机·主流）、414×896（手机·大屏）、768×1024（平板）四档视口下检查。四种宽度下五个位置始终等分、文字不换行不溢出、中间按钮的凸起量保持一致，说明 flex: 1 1 0 与 min-width: 0 的配合是有效的。

图 8　1440×900 桌面浏览器下的表现（内容限宽 750px 居中）

3.2 多浏览器测试

在 Google Chrome 与 Microsoft Edge 两种浏览器中打开同一页面并截图对比。由于两者同为 Chromium 内核，渲染结果一致，下导航的尺寸、圆角、颜色与凸起位置没有差异；两版的截图在 375×812 下逐像素相同，说明页面没有依赖某一浏览器的私有特性。

3.3 页面跳转测试

五个导航项都指向真实页面，不是空链接。点击每一项都能跳转到对应页面，且目标页面上的对应项处于选中态；中间的发布按钮跳转到发布页，该页作为模态页刻意不显示下导航，避免页面上出现两个红色按钮。

图 11　五个页面：每个导航项都有独立页面（发布页为模态页，隐藏导航）

3.4 发布

项目为纯静态页面，通过本地静态服务器发布验证：在 mobile 目录执行 python -m http.server 8899 后，访问 http://127.0.0.1:8899/index.html 即可打开首页。实测六个页面、两个样式表与三个字体文件全部返回 200（其中 font/iconfont.woff2 为 8476 字节），没有任何 404，说明页面不依赖本地文件路径，整体上传到任意静态服务器即可访问。
