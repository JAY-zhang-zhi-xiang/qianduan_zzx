## 虎扑移动端「不满屏」修复（13:30）
- 用户反馈：电脑里打开 `hupu/mobile/index.html` 两侧是灰底、页面只有 750px 居中，像没铺满。
- 原因：`.zzx-page` 用 `max-width: var(--zzx-page)` + `margin: 0 auto` 把**整个页面**限宽了，桌面媒体查询又把 body 设成 `#e9ebee`，于是两侧灰边特别明显。自适应本身没问题（导航 flex 五等分、`min-width:0`、safe-area 都在）。
- 改法：页面本体 `width:100%` 铺满窗口；把 `max-width + margin:auto` 下移到 `.zzx-header / .zzx-channels / .zzx-score / .zzx-feed / .zzx-hot / .zzx-talk` 六个内容区块，内容居中、底色全屏。删除桌面查询里 `body: #e9ebee`、`.zzx-page` 阴影、`.zzx-tabbar` 透明那一套。
- 踩坑：`.zzx-score` 原本 `margin: 10px 12px` 的简写会覆盖前面的 `margin-left/right:auto`，导致比分条贴左。改成 `margin: 10px auto` 才真正居中——**CSS 简写属性的覆盖顺序要留意**。
- 报告配图更新：`nav-375.png`、`nav-closeup.png`、`nav-viewports.png`（320/375/414/768）重拍，新增 `nav-desktop.png`（1440 铺满 + 内容居中）。
- 结论：移动端页面用「全屏白底 + 内容限宽居中」比「整页限宽 + 灰底」观感好得多，交付前应该按这个来。
