JavaScript 程序结构

一个程序由"顺序、条件、循环"三种基本结构组成。 下面分别用可运行的例子演示这三种结构是如何配合工作的。

一、程序结构（顺序执行）

从上到下，依次执行

顺序结构是最基础的结构：语句按书写顺序一条条执行。下面计算三科成绩的总分与平均分。

// 1. 声明变量
var zzxChinese = 92;
var zzxMath = 88;
var zzxEnglish = 95;

// 2. 运算
var zzxTotal = zzxChinese + zzxMath + zzxEnglish;
var zzxAvg = zzxTotal / 3;

// 3. 输出结果
console.log("总分：" + zzxTotal);
console.log("平均分：" + zzxAvg.toFixed(1));

二、条件语句

if / else if / else · switch

根据条件选择不同的执行路径。输入一个分数（0~100），判断等级。

var zzxScore = 85;
if (zzxScore >= 90) {
    console.log("优秀");
} else if (zzxScore >= 80) {
    console.log("良好");
} else if (zzxScore >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}

三、循环语句

for · while

重复执行一段代码。用 for 求 1~100 的和，用 while 列出 1~20 的偶数。

// for 循环：1 加到 100
var zzxSum = 0;
for (var i = 1; i <= 100; i++) {
    zzxSum += i;
}

// while 循环：列出 1~20 的偶数
var j = 1;
while (j <= 20) {
    if (j % 2 === 0) console.log(j);
    j++;
}
