对象：一张带标签的信息卡

变量只能装一个值，对象却能装一整组——每一条数据都有自己的名字， 叫"属性"；属性里放函数，就叫"方法"。下面这张卡片，就是一个对象。

一、对象的结构

属性名 : 属性值 

                        

                            左边是人能看懂的样子，右边是代码的样子。
                            每个属性都是 键 : 值 的组合，值可以是字符串、数字、布尔值，也可以是函数。

三、对象里的方法

                    属性值是函数 · this 指向对象自己
                

                

                    

                        
var zzxStudent = {
    name: "张志翔",
    age: 20,
    sayHi: function () {
        // this 就是 zzxStudent 本身
        return "大家好，我是" + this.name
             + "，今年 " + this.age + " 岁。";
    }
};

                        

                            
                        

                    

                    

                        

                            调用结果会出现在这里
                            先点左边的按钮试试。
                        

                        

                            方法也是属性，只不过它的值是一个函数。
                            里面的 this 指向调用它的那个对象，所以能读到自己的 name 和 age。
                        

                    

                

            


            
            

                

                    
四、用构造函数批量造对象

                    function + new
                

                

                    

                        
// 构造函数：首字母大写，相当于一张空表格
function zzxStudentCard(name, age, major) {
    this.name = name;
    this.age = age;
    this.major = major;
}

// new 会新建一个空对象，把 this 指向它
var zzxA = new zzxStudentCard("小志", 20, "数字媒体技术");
var zzxB = new zzxStudentCard("小翔", 21, "视觉传达");
var zzxC = new zzxStudentCard("小张", 19, "计算机科学");

                    

                    

                        

                        

                            同一张"表格"填三次，就得到三个互不干扰的对象。
                            改其中一个的 age，另外两个不会跟着变。
                        

                    

                

            


            
            

                

                    
五、遍历对象的属性

                    for...in · Object.keys · Object.values
                

                
// for...in：把所有属性名依次取出来
for (var zzxKey in zzxStudent) {
    console.log(zzxKey);
}

// 只想拿属性名或属性值，可以这样
Object.keys(zzxStudent);     // ["name", "age", ...]
Object.values(zzxStudent);   // ["张志翔", 20, ...]

                

                

                    三种写法拿到的东西不同：for...in 边遍历边处理，
                    Object.keys / values 一次性把属性名或值装进数组，方便继续用数组的方法处理。
