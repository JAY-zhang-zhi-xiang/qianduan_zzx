# 高级网页设计课堂实践

欢迎来到张志翔的《高级网页设计》课堂实践项目！本项目包含多个网页，展示了CSS的进阶知识和相关实践。

## 项目文件

- **index.html**: 主题为张志翔的《高级网页设计》课堂实践，包含全部课程练习页面的超链接。
- **4-1 css2.html**: 展示了CSS的进阶知识，包含样式和内容。
- **styles/main.css**: CSS样式表，用于美化`index.html`和其他HTML页面的外观。

## 使用方法

1. 打开 `index.html` 文件以查看项目的主页。
2. 从主页中可以访问全部课程练习页面，包括 HTML、CSS、盒模型和 Flex 布局等练习。
3. 根据需要修改样式表 `styles/main.css` 来调整页面外观。
